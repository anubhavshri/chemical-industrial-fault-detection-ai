# 🏭 Chemical Industrial Fault Detection AI

An advanced industrial fault detection framework using deep learning architectures for intelligent monitoring and anomaly detection in complex chemical process environments.

---

## 🚀 Overview

This project focuses on intelligent fault detection in industrial chemical processes using machine learning and deep learning techniques on the Tennessee Eastman Process (TEP) benchmark dataset.

The system analyzes multivariate industrial sensor data to identify abnormal operating conditions, process disturbances, and hidden fault patterns in real-time environments.

The project includes:
- Deep learning-based fault detection
- Industrial process monitoring
- Comparative ML/DL model analysis
- Streamlit-based interactive frontend
- Research-oriented experimentation pipeline

---

## 🧠 Proposed Architecture

The proposed framework explores advanced spatio-temporal learning techniques for industrial anomaly detection.

Models explored include:
- PCA
- Random Forest
- CNN
- CNN-LSTM
- Hybrid GNN + Attention + Bi-GRU Architecture

The hybrid model captures:
- Spatial sensor relationships
- Temporal process dependencies
- Dynamic fault propagation patterns
- Long-term industrial process behavior

---

## 📊 Dataset

The project uses the Tennessee Eastman Process (TEP) dataset, a widely used benchmark dataset for industrial fault detection research.

Features:
- 52 process variables
- Multivariate time-series data
- 21 operating/fault conditions
- Realistic industrial process simulation
