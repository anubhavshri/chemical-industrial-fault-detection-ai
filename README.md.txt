EARLY FAULT DIAGNOSIS DEMO - QUICK START

1. Extract this ZIP file to any folder.
2. Double-click run_demo.bat
3. Wait while it installs required packages.
4. Your browser should open automatically.
5. If browser does not open, copy the local URL from the black command window.

IMPORTANT:
- Python must already be installed on your system.
- During Python installation, enable: Add Python to PATH

FILES:
- fault_diagnosis_demo_app.py  -> main app
- requirements.txt            -> required packages
- run_demo.bat                -> double-click to run
